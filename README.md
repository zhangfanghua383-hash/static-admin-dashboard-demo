# SlateOps Admin Dashboard Demo

A responsive static admin dashboard demo built for portfolio use. This repository is a standalone static UI project.

## Features

- Pure HTML5, CSS3, and vanilla JavaScript
- Responsive sidebar: desktop collapse + mobile drawer
- Top navigation with search, notification, and profile UI
- Dashboard page with KPI cards, SVG line chart, CSS donut chart, and recent orders table
- Users page with client-side search, role filter, and pagination
- Settings page with form fields, preferences toggles, compact table mode, and toast feedback
- No backend, database, framework, bundler, or external JavaScript dependency

## Local Preview

Open `index.html` directly in a browser, or serve the folder with any local static server.

## Project Scope

This is a portfolio demo, not a production application. The data is static sample data, and actions such as CSV export or adding a user are simulated with UI feedback.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- SVG/CSS charts
